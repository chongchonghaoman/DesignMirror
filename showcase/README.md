# TikTok Brand Hub - Design Showcase

> Built with DesignMirror design tokens

This page demonstrates a TikTok-inspired brand landing page using design tokens extracted and analyzed through DesignMirror.

## Design Tokens Used

### Colors

| Token | Hex | Usage |
|-------|-----|-------|
| Primary | `#7AD1DD` | Ocean blue brand color |
| Accent | `#FF00A1` | Bright pink CTA |
| Warm Accent | `#FFC65D` | Golden highlights |
| Background | `#0A0A0F` | Dark theme base |

### Typography

| Element | Font | Size/Weight |
|---------|------|-------------|
| Display | Poppins | Variable / bold |
| Heading | Barlow Condensed | Variable / medium |
| Body | Inter | 13-18px / 400-500 |

### Spacing

8px base grid system: xs(4px), sm(8px), md(16px), lg(32px), xl(48px+)

## Features Demonstrated

- Dark theme with warm golden accents
- Coverflow carousel showcase
- Feature cards with hover effects
- Animated floating elements
- Responsive design
- Glass morphism navigation
- Dark/Light mode toggle

## Usage

Open this file directly in a browser. No build step required.

```bash
# From the DesignMirror root:
open showcase/tiktok-brand.html
```

## Tech Stack

- Tailwind CSS (CDN)
- Vanilla JavaScript
- Google Fonts (Poppins, Barlow Condensed, Inter)
- CSS Custom Properties for theming

## Source

This design was created by analyzing a TikTok-style creative platform through DesignMirror, extracting the design tokens, and applying them to a new brand landing page concept.
